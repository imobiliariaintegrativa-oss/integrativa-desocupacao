Política de Privacidade

Sistema Integrativa Desocupação · Imobiliária Integrativa · Atualizada em novembro de 2026

1. Sobre o sistema

O Integrativa Desocupação é um sistema interno da Imobiliária Integrativa para acompanhar desocupações de imóveis, vistorias, reparos, orçamentos e rescisões de contratos de locação. O acesso é restrito a funcionários autorizados, mediante login com e-mail e senha.

2. Dados tratados

O sistema armazena dados necessários à gestão das desocupações: número do contrato, nome do locatário, endereço do imóvel, datas das etapas (comunicação, vistoria, entrega de chaves), reparos, orçamentos de prestadores (nome, telefone, valores) e informações da rescisão. Também guarda nome, e-mail e senha criptografada dos usuários do sistema.

3. Uso do Google Drive

O sistema usa a API do Google Drive apenas para salvar os arquivos de orçamentos enviados pelos funcionários, em pastas criadas pelo próprio sistema na conta Google da imobiliária. O acesso solicitado é o escopo drive.file, que permite ao sistema ver e gerenciar somente os arquivos e pastas que ele mesmo criou. O sistema não lê, não lista e não altera nenhum outro arquivo do Google Drive.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

4. Compartilhamento

Os dados não são vendidos nem compartilhados com terceiros para fins comerciais. Orçamentos podem ser encaminhados a seguradoras, garantidoras ou ao jurídico exclusivamente para a análise e o pagamento dos reparos do imóvel, conforme o contrato de locação.

5. Armazenamento e segurança

Os dados ficam em banco de dados protegido e só podem ser acessados por usuários autenticados. As senhas são armazenadas de forma criptografada. Os arquivos de orçamentos ficam no Google Drive da imobiliária.

6. Direitos dos titulares

Conforme a Lei Geral de Proteção de Dados (LGPD), o titular pode solicitar acesso, correção ou exclusão de seus dados pessoais pelo e-mail imobiliariaintegrativa@gmail.com.
